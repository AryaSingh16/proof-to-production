# Security Policy

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do not disclose it publicly via GitHub issues.

### How to Report
1. Email details of the vulnerability to the project maintainers or use GitHub's private vulnerability reporting feature.
2. Include a description of the issue, steps to reproduce, and any relevant logs or proof of concept.
3. Maintainers will review the report and respond within 48 hours to coordinate a fix and release.

Thank you for helping keep our software and supply chain secure.
